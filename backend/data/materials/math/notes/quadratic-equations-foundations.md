# 二次方程：概念與解題檢查

本筆記以自己的文字整理二次方程的基礎概念，不是考評局試題或評分參考。

## 標準形式

一元二次方程可寫成 ax² + bx + c = 0，其中 a、b、c 是常數，而且 a 不等於 0。解方程的目標是找出令等式成立的 x 值。

## 三種常用方法

1. 因式分解：把左邊寫成兩個一次因式的乘積。若 (px + q)(rx + s) = 0，則 px + q = 0 或 rx + s = 0。
2. 配方法：把含 x 的二次式整理成平方項加或減常數，再利用平方關係求根。
3. 求根公式：x = (−b ± √(b² − 4ac)) / (2a)。使用前先確認方程已整理成標準形式，並辨認 a、b、c。

## 判別式

判別式 Δ = b² − 4ac。Δ 大於 0 時有兩個不相等的實根；Δ 等於 0 時有一個重根；Δ 小於 0 時沒有實根。判斷根的數目時，只需計算 Δ 的正負，不必先求出根。

## 解題後檢查

- 把答案代回原方程，檢查等式左右是否相等。
- 因式分解時，展開因式確認係數沒有抄錯。
- 使用求根公式時，根號內必須是同一個判別式 b² − 4ac。
- 若題目有分母或其他限制，檢查候選根是否令原式無定義。
