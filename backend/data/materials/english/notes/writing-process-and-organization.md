# English Writing: Planning, Paragraphing and Revision

This is an original study note about general writing practice. It is not an HKEAA question, marking scheme, or model essay.

## Plan for the reader

Before drafting, identify the purpose, audience and text type. List the key message and group related supporting ideas. A simple outline helps keep each paragraph focused and prevents unrelated points from being added late.

## Build a clear structure

- Opening: establish the topic and make the purpose clear.
- Body paragraphs: give each paragraph one main idea, then explain or illustrate it with relevant details.
- Ending: bring the message to a natural close rather than introducing a new argument.

Use linking words only when they express the actual relationship between ideas, such as contrast, cause, sequence or addition. Paragraph order should make the line of thought easy to follow.

## Revise in passes

1. Content: check that the response addresses the task and develops relevant ideas.
2. Organization: check paragraph focus, order and links between ideas.
3. Language: check grammar, word choice, spelling and sentence clarity.
4. Task fit: check tone, format and details expected for the intended audience and text type.

Reading the draft once for meaning and once for language makes it easier to notice different kinds of problems. Prefer precise, familiar wording over a complicated phrase used only to sound formal.
